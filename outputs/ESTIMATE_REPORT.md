**유형이 갈리는 지점**

- **A와 B의 차이는 "막힌 판"이 나오는지**입니다. A는 정답이 화면에 이미 있어 못 푸는 판이 생기지 않습니다. B는 트레이·보관대가 차면 실패라 **모든 시드가 클리어 가능함을 보장**해야 하고, 여기에 생성기와 검증기가 따로 붙습니다(실제로 플레이트 스택은 시드 1,000개 전량 클리어 가능성을 검증했습니다).
- **C는 아트가 아니라 손맛이 비쌉니다.** 절단 지오메트리와 파티클은 구현보다 튜닝에 시간이 들고, 저사양 단말 프레임 유지까지 봐야 합니다.
- **D는 상태머신이 동시에 여러 개 돕니다.** 조리·손님 인내·대기열·현금이 서로 물려 있어 하나를 고치면 밸런스가 전부 흔들립니다. 아트 물량도 가장 많습니다.

## 4. 4주 안에 몇 개가 가능한가

79.5 인·일 ÷ 20 영업일 ≈ **4트랙**이 있어야 8종 전부가 4주에 들어갑니다.

| 투입 | 4주 산출 | 권장 조합 |
|---|---|---|
| 1트랙 | **2–3종** | A 3종, 또는 A 2종 + B 1종 |
| 2트랙 | **5–6종** | A 3종 + B 2종 + C 1종 |
| 3트랙 | 7종 내외 | A 3종 + B 2종 + C 2종 |
| **4트랙** | **8종 전부** | 개발 4인 + 아트 1.5인 + QA 1인 |

**수량을 늘리는 현실적인 방법 두 가지**

1. **유형을 섞지 말고 A부터 채우기.** 같은 4주라도 A만 뽑으면 1트랙 3종, 2트랙 6–7종까지 나옵니다. D 한 종이 A 세 종의 공수를 먹습니다.
2. **공용 셸을 먼저 세우기.** 첫 타이틀에 붙는 +2일은 한 번만 냅니다. 물량이 늘수록 타이틀당 실효 단가가 내려갑니다.

**병렬화가 안 되는 구간** — 승인·피드백 반영은 트랙 수와 무관하게 직렬입니다. 4트랙으로 4주를 잡을 경우 검수 일정이 병목이 되므로, 주 2회 고정 리뷰 슬롯을 전제로 합니다.
