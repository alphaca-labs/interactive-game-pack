## 구현 요지

- **정규화 좌표 단일화** — 절단 위치는 `0..1`로만 저장하고, 포인터 `clientX`를 매 입력 시 최신 `getBoundingClientRect()`에 투영한다. 리사이즈·회전 뒤에도 절단 위치와 점수가 그대로다.
- **순수 점수 함수** — `calculateScore(cuts)`는 DOM 비의존. 조각 폭의 정규화 표준편차 `d`로 `round(100 × clamp(1 − d/0.60, 0, 1))`. 1/6 간격 5회 절단이 정확히 100점.
- **입력 동등성** — Pointer Events와 키보드가 같은 `knifeX → commitCut()` 경로를 쓴다. 첫 포인터만 인정하고 `pointercancel`·창 blur는 절단으로 처리하지 않는다.
- **경쟁 조건 차단** — 모든 타이머·애니메이션 콜백이 생성 시점 `roundId`를 검사한다. 5번째 칼질이 들어오는 순간 rAF 타이머를 즉시 정지시켜, 절단 연출 280ms 중 시간이 0이 되어 완주가 시간 종료로 뒤집히는 문제를 구조적으로 없앴다.
- **무효 절단** — 기존 경계 4.5% 미만은 칼질을 차감하지 않고 안내·진동 표현만 낸다(`isValidCut`).
- **절차적 에셋** — 외부 이미지·폰트·오디오 파일 0개. 오이는 인라인 SVG 원본 도형 하나를 조각별 `clipPath`로 분절하고, 파티클은 10개 풀을 재사용한다. 사운드는 기본 꺼짐이며 사용자가 켠 뒤에만 Web Audio로 절차 생성한다.
- **접근성** — 칼은 `role="slider"`(값·남은 칼질을 `aria-valuetext`로 노출), `aria-live="polite"`로 시작·유효/무효 절단·10초/5초 경고·결과 안내. 버튼 44px 이상, 성공/실패는 색상 외 아이콘·문구 병기, `prefers-reduced-motion`에서 파티클·흔들림·카운트업 제거.
