## 제작 전제(견적 입력값)

- 산출물은 반응형 HTML5 플레이어블 데모. 세로 모바일 최적화, 마우스·터치·키보드 모두 조작 가능.
- 각 데모 구성: 시작 상태 → 짧은 튜토리얼 큐 → 코어 루프 → 성공/실패 피드백 → 재시작 → 점수/진행률 → 비상업용 데모 CTA.
- 아트는 CSS/SVG/절차적 생성 기반 오리지널. 원본 게임의 로고·캐릭터·스크린샷·추출 에셋은 일절 사용하지 않는다(레퍼런스는 메커니즘만 참고).
- 인력 전제: 시니어 HTML5 개발 1인 + UI/아트 0.5인 + QA 0.5인 = 1개 트랙. 1레벨, 국문 UI, 승인 1회, 사운드 옵션, 광고 SDK 패키징 미포함.
- 첫 타이틀에는 공용 셸(부트·상태머신·입력·HUD·리사이즈) 구축분 **+2 영업일**이 추가로 든다. 2번째 타이틀부터는 셸 재사용을 전제로 한다.

## 구현 방향(다음 단계 인계)

- `games/<slug>/index.html` 로 게임별 완전 독립 폴더 — 한 데모가 깨져도 다른 데모에 영향이 없어야 한다.
- DOM/CSS + 인라인 벡터/절차적 아트 우선. 번들 경량화와 라이선스 명확성 확보.
- 무료 에셋을 쓸 경우 CC0/OFL 계열만 사용하고 출처를 `ASSETS.md` 에 남긴다.
- `prefers-reduced-motion` 존중, 포커스 표시 유지, 인터랙션 타깃 최소 44px.
- GitHub Pages 배포 시 루트 인덱스에서 8종 데모 + 출처 그룹(6초/1분45초 이후) + 유형 + 공수 밴드를 노출한다. 원본 브랜딩(로고·타이틀)은 재현하지 않는다.
