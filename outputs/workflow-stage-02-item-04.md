## 구현한 규칙

- 5열 × 4행 20칸, 목표 재료 정확히 5칸. 오답은 5~8종이며 **종당 최대 4칸** — 5칸인 재료는 목표뿐이라 정답이 언제나 유일하게 결정된다.
- 목표와 **같은 실루엣 계열**(배↔가지, 양파↔마늘, 토마토↔사과, 당근↔고추, 버섯↔브로콜리, 달걀↔밤, 감자↔호박)은 같은 라운드의 오답으로 등장하지 않는다.
- 30초 제한. 별도 시작 버튼 없이 **첫 유효 입력**이 타이머를 시작한다.
- 정답 `100 × 콤보`(1.00 → 1.25 → 1.50 → 1.75 → 2.00 상한), 오답 시간 −2초 · 점수 −50(하한 0) · 콤보 초기화.
- 오답 칸은 제거하지 않고 450ms X 표식 + **해당 칸만** 입력 잠금 → 재탭 중복 차감 없음. 다른 칸은 계속 조작 가능하다.
- 승리 시 `floor(남은 초) × 10` 시간 보너스를 한 번만 가산. `finishOnce` 가드로 마지막 정답과 타이머 만료가 경합해도 먼저 확정된 결과만 기록한다.
- 타이머는 `performance.now()` 단조 시계 기준이며, 탭이 숨겨지면 일시정지하고 복귀 시 이어서 진행한다.
