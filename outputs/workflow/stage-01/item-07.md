| 구분 | 계획값 | 근거 |
|---|---:|---|

| 오리지널 아트·UI | 2인일 | 도구 SVG 12종, 주방 장면, 반응형·감소 모션, 합성 효과음 |

| 타이틀당 제작 기간 | **5~7영업일** | 내부 확인·승인 1회·수정 버퍼 포함 |

전제는 선임 HTML5 개발 1인 + UI/아트 0.5인 + QA 0.5인, 단일 레벨, 한국어, 내부 QA와 수정 1회다. 공용 셸을 이 게임에서 처음 구축하면 2영업일을 프로젝트 공통 공수로 별도 배정하며, 브랜드 일러스트·전문 음원·추가 레벨·다국어·분석/광고 SDK는 별도 견적이다.

## 개발 인계 우선순위

1. `createRound(seed)`로 정확히 8종×3개를 만들고 4×6 논리 앵커에 최소 44px 비중첩 hit area를 보장한다.
2. 도구 선택, 7칸 바구니, 트리플 제거, 성공, 바구니 실패, 시간 실패를 순수 상태 전이로 구현하고 **트리플 → 성공 → 실패** 판정 순서를 테스트로 고정한다.
3. 12종 자체 SVG와 주방 배경, 바구니 이동·비눗방울·합성음을 붙인 뒤 `prefers-reduced-motion` 대체를 구현한다.
4. 연타·마지막 탭/타이머 경합, seed 100회, 5개 뷰포트, 키보드·VoiceOver, 오프라인 직접 실행을 검증한다.

## 완료 판정

- 고정 seed에서 24개와 8종×3개 불변식, 선택 가능한 44px 비중첩 영역이 보장된다.
- 일곱 번째 도구가 트리플을 완성할 때는 실패하지 않고, 비매칭 7칸·시간 만료·마지막 탭 경합은 각각 한 번만 종료된다.
- 포인터·터치·키보드로 완주 가능하고 200% 확대, 음소거, 축소 동작, 강제 색상, 여유 모드에서도 정보 손실이 없다.
- `games/kitchen-tidy/index.html`을 네트워크 없이 직접 열어 한 판·결과·재시작을 완료하며 외부 요청과 콘솔 오류가 0건이어야 한다.
- GitHub Pages 루트 인덱스에는 `1분45초 이후 / Type A / 5~7일 / ₩4.5M~₩6.5M` 메타데이터와 함께 데모를 연결한다.
