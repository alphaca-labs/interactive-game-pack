## 확정한 제품 정의

눈 내리는 산장 식료품 저장고에서 목표 카드가 요구하는 재료 5개를 5×4 그리드에서 찾아 제한 시간 안에 수집하는 세로형 HTML5 미니게임으로 기획했다. 한 판은 첫 입력부터 30초이며, 정답 수집·오답 페널티·콤보 점수·승패·재시작까지 20~45초 안에 경험하도록 고정했다.

핵심 규칙은 다음과 같다.

1. 총 20칸 중 목표 재료를 정확히 5칸에 배치한다.
2. 정답은 `100 × 콤보 배수`, 오답은 시간 `-2초`, 점수 `-50`, 콤보 초기화로 처리한다.
3. 5개를 모두 수집하면 즉시 승리하고, 5개 미만인 채 시간이 0이 되면 실패한다.
4. 마지막 정답과 타이머 만료가 경합하면 유효한 선택 입력의 승리를 먼저 확정한다.
5. 포인터·터치·키보드는 모두 같은 선택 로직을 사용하며, 목표·피드백은 색상에만 의존하지 않는다.

## 제작 사양

- 경로: `games/winter-pantry/`
- 파일: `index.html`, `style.css`, `script.js`
- 실행: 외부 네트워크·공유 모듈 없이 `file://`에서도 완전한 한 라운드와 재시작 가능
- 화면: 5×4 고정 그리드, 최소 44px 탭 영역, 320×568부터 데스크톱·가로 화면 대응
- 에셋: 20종 재료·산장·선반·난로·바구니를 자체 제작 인라인 SVG와 CSS 도형으로 구성
- 접근성: 키보드 완주, `aria-live`, 명확한 포커스, reduced motion·forced colors 대응
- 재현성: `?seed=` 고정 보드, `?test=1` 규칙 자기 테스트
- 비범위: 원작 로고·캐릭터·캡처·음원, 외부 SDK/분석, 스토어 연결, 서버 저장, 추가 레벨·다국어

## 일정·견적·4주 생산성

| 구분 | 계획값 | 근거 |
|---|---:|---|
| 로직·상태·입력 | 2인일 | seeded 보드, 점수·시간, 경계 판정, 멀티 입력, 재시작 |
| 오리지널 아트·UI·모션 | 2인일 | 재료 SVG 20종, 산장 장면, 반응형·감소 모션, 합성 효과음 |
| QA·튜닝 | 1인일 | 모바일·데스크톱·접근성·오프라인 회귀, 난이도 조정 |
| 타이틀당 제작 기간 | **5~7영업일** | 내부 확인·승인 1회·수정 버퍼 포함 |

| 1트랙 4주 최대 | **3종** | 최초 공용 셸 +2일을 포함한 20영업일 기준 |
| 2트랙 4주 최대 | **6~7종** | 아트·QA 병목과 승인 버퍼 반영 |

브랜드 일러스트, 녹음 음원, 분석·광고 SDK, 현지화, 추가 레벨은 별도 견적이다. 주요 변동 위험은 재료 20종의 작은 화면 판별성, 320px 폭에서 44px 타깃 유지, 마지막 탭과 타이머 만료의 경쟁 조건이다.

## 개발 인계 및 완료 기준

- 상태 흐름 `BOOT → READY → PLAYING → RESOLVING → WON/LOST`와 단일 종료 가드를 구현한다.
- 고정 seed에서 항상 20칸·목표 5칸이 생성되고, 목표와 혼동되는 실루엣·색 변형은 같은 라운드에 배치하지 않는다.
- 정상 승리, 오답 페널티, 시간 실패, 마지막 탭 경합, 재시작, 키보드 완주, 감소된 모션, 오프라인 직접 실행, 4개 기준 뷰포트를 인수 테스트로 통과한다.
- 외부 요청과 콘솔 오류는 0건이어야 하며 재시작 20회 후에도 타이머·이벤트가 중복되지 않아야 한다.
- GitHub Pages 루트 인덱스에는 `6초 시점 / Type A / 5~7일 / ₩4.5M~₩6.5M` 메타데이터와 함께 이 데모를 연결한다.
