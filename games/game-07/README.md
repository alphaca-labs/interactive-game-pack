# 07 · 키친 타이디 (Kitchen Tidy)

8종 데모 패키지 중 **7번**. 참조 영상 `xQH4X57HKQo`의 `01:52~02:20` 세 번째 패널 — 주방 바닥에 흩어진 조리도구가 시간이 지나며 사라지는 장면에서 도출한 **Type A · 탭 매칭** 프로토타입.

기획서: [`outputs/plans/kitchen-tidy.md`](../../outputs/plans/kitchen-tidy.md)

## 실행

빌드·설치·서버가 필요 없다. `index.html`을 브라우저에서 그대로 열면 된다.

```
open games/game-07/index.html
```

`file://`로 열어도 외부 요청·CORS 오류 없이 한 판, 결과, 재시작이 전부 동작한다.

### URL 파라미터

| 파라미터 | 동작 |
|---|---|
| `?seed=<문자열>` | 같은 배치를 재현한다. 재시작해도 같은 판이 나온다. |
| `?test=1` | 시작 화면을 건너뛰고 순수 함수·상태 전이·렌더 불변식 자동 검증(38건)을 실행한다. 결과는 콘솔·`document.title`·`window.__ktTest`. |
| `?relax=1` | 여유 모드(제한 시간 없음)를 체크한 상태로 시작한다. |

## 규칙

- 조리도구 **8종 × 3개 = 24개**가 4열 × 6행 논리 앵커에 흩어진다.
- 도구를 탭하면 하단 **7칸 정리 바구니**로 들어간다. 같은 종류 3개가 모이면 자동으로 사라진다.
- **35초** 안에 8세트를 모두 치우면 성공. 바구니에 짝이 없는 도구 7개가 차거나 시간이 끝나면 실패.
- 점수: 트리플당 100점, 이전 트리플 후 4초 안에 다음 트리플을 완성하면 `+25 × 연속 단계`(3단계 +75 상한), 성공 시 `남은 초 × 10` 보너스, 힌트 사용 시 최종 −100(하한 0).
- 힌트는 7초 동안 진행이 없을 때 1회 활성화되며, 완성 가능한 한 종류를 1.2초간 **테두리와 ◆ 심볼**로 표시한다(색만으로 알리지 않는다).

> 3개 매칭·7칸 바구니·35초 제한·점수 산식은 원본 영상에서 확인되지 않아 이 프로토타입이 독자 설계한 값이다. 기획서 §1의 「구현 가정」과 같다.

### 판정 순서 (바꾸면 조용히 깨진다)

```
입력 재진입 잠금 → 도구 이동 → 트리플 탐색·제거 → 성공 확인 → 바구니 초과 확인 → 잠금 해제
```

바구니 초과 확인을 트리플 제거보다 앞에 두면 **일곱 번째 도구가 트리플을 완성하는데도 실패 처리**된다. 이 순서는 `script.js`의 `selectTool()`과 자동 검증의 「7번째가 트리플이면 실패하지 않음」 검사로 고정돼 있다.

`selectTool()`은 전 구간이 동기라 타이머(rAF)가 중간에 끼어들 수 없다. 따라서 마지막 탭과 시간 만료가 같은 프레임에 겹쳐도 탭 처리가 먼저 끝나고, `finishOnce()` 단일 가드가 그 뒤의 시간 종료를 무시한다.

## 조작

| 입력 | 동작 |
|---|---|
| 클릭 / 탭 | 도구 선택 |
| `Tab` / `Shift+Tab` | 남은 도구·HUD 순회 |
| 방향키 | 화면 좌표 기준으로 그 방향에서 가장 가까운 남은 도구로 이동 |
| `Enter` / `Space` | 선택 |
| `H` | 힌트 · `M` 음소거 · `R` 결과 화면에서 재시작 |

포인터·터치·키보드는 모두 `selectTool(id)` 하나로 진입해 점수·시간·판정이 동일하다.

## 접근성 · 반응형

- 도구는 네이티브 `<button>`이고 접근성 이름은 `프라이팬, 바닥 2행 3열`처럼 종류와 논리 위치를 포함한다.
- 바구니는 조작 대상이 아니라 `프라이팬 2개, 머그 1개, 총 3/7` 텍스트 요약을 제공한다. 트리플·힌트·종료는 `aria-live="polite"`로 알린다.
- 타이머는 화면에 계속 표시하되 낭독은 10초·5초만 한다. 시작 화면의 **여유 모드**를 켜면 제한 시간이 없어지고 기록에 `연습`으로 표시된다.
- 모든 도구 hit area는 **44×44px 이상이며 서로 겹치지 않는다**. 흩어진 느낌은 셀 안쪽의 제한된 흔들림(±10%/±8%)과 회전(±10°)으로만 만들고, 그 상한은 셀 간격보다 작게 잡혀 있다.
- `prefers-reduced-motion: reduce`에서 이동·회전·맥동·파티클을 제거한다. 판정 순서는 동일하다.
- 320×568 / 390×844 / 844×390 / 768×1024 / 1440×900 에서 가로 스크롤·겹침·잘린 조작이 없다. 720px 이상 또는 가로 방향에서는 왼쪽 주방 · 오른쪽 HUD·바구니 2열로 전환한다.

## 에셋

조리도구 12종(팬·냄비·주걱·거품기·그릇·머그·주전자·토스터·와플팬·도마·절구·오븐장갑), 주방 배경, 바구니, 파티클은 전부 인라인 SVG와 CSS로 직접 그렸다. 소리는 Web Audio 합성음이며 **첫 사용자 제스처 이후에만** AudioContext를 만든다(제스처 없이 만들면 브라우저가 호출마다 autoplay 경고를 남긴다). 외부 이미지·웹폰트·CDN·음원 요청은 0건이고, 원본 영상의 로고·캐릭터·UI 캡처·추출 음원은 사용하지 않았다.
