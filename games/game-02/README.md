# 퍼펙트 슬라이스 (Perfect Slice)

플레이어블 광고 데모 8종 중 **항목 2 / Type C — 물리·파티클**.
칼을 좌우로 조준해 오이를 **5번 잘라 6조각**으로 나누고, 조각 두께 편차를 정확도 점수로 환산한다.

- 기획서: `outputs/plans/perfect-slice.md`
- 원본 근거: YouTube `xQH4X57HKQo` `00:06` 4패널 중 2번 패널

## 실행

빌드·설치·서버가 필요 없다. `index.html`을 브라우저에서 직접 열면 된다(`file://` 포함).
외부 요청 0건 — 이미지·폰트·오디오 파일·SDK를 쓰지 않고 CSS와 인라인 SVG, Web Audio 절차 생성만 사용한다.

디렉터리는 워크플로 배포 단계의 항목 번호 규약을 따라 `games/game-02/`이며, 게임 슬러그는 `perfect-slice`다.

```
games/game-02/
├── index.html   구조 · 인라인 SVG 원본 도형(오이/칼/심사 스티커)
├── style.css    레이아웃 · 도마/칼 질감 · 반응형 · 감소된 모션
└── script.js    규칙 · 점수 · 상태머신 · 입력 통합 · 렌더링
```

## 규칙

| 항목 | 값 |
|---|---|
| 절단 횟수 | 5회 (→ 6조각) |
| 제한 시간 | 25초 (`시작` 이후부터) |
| 무효 절단 | 기존 경계에서 4.5% 미만 → 칼질 차감 없음, 안내만 |
| 점수 | `round(100 × clamp(1 − d / 0.60, 0, 1))`, `d` = 조각 폭의 정규화 표준편차 |
| 성공선 | 65점 이상 |
| 등급 | 90+ 완벽한 칼질 · 80+ 셰프급 · 65+ 좋아요 · 그 외 한 번 더 |

정규화 좌표 `0..1`이 단일 진실 공급원이라 리사이즈·회전 후에도 절단 위치와 점수가 보존된다.

## 조작

- **포인터/터치** — 도마 위를 누른 채 좌우로 끌었다 놓으면 그 지점에서 잘린다. 첫 포인터만 인정하고, `pointercancel`·창 포커스 이탈은 절단으로 처리하지 않는다.
- **키보드** — 칼은 `role="slider"`. `←/→` 1.5%, `Shift+←/→` 5%, `Home`/`End` 양 끝, `Space`/`Enter` 절단(intro에서는 시작).

## 접근성

`aria-live="polite"` 상태 영역으로 시작·유효/무효 절단·10초/5초 경고·결과를 알린다.
모든 버튼 44px 이상, 색상에만 의존하지 않는 성공/실패 표시, `prefers-reduced-motion: reduce`에서 파티클·흔들림·점수 카운트업 제거.
사운드는 기본 꺼짐이며 사용자가 켠 뒤에만 Web Audio로 절차 생성한다.
