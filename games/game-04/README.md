# 윈터 팬트리 (Winter Pantry)

플레이어블 광고 데모 8종 중 **항목 4 / Type A — 탭 매칭**.
눈 내리는 산장 저장고에서 **30초** 안에 목표 재료 **5개**를 5×4 선반에서 찾아 수집한다.

- 기획서: `outputs/plans/winter-pantry.md` · 인계서: `outputs/workflow/stage-01/item-04.md`
- 원본 근거: YouTube `xQH4X57HKQo` `00:06` 4패널 중 4번 패널(설원 오두막 서사 컷 + 목표 카드 ×5 + 하단 5×4 식재료 그리드)

디렉터리는 배포 단계의 항목 번호 규약을 따라 `games/game-04/`이며, 게임 슬러그는 `winter-pantry`다.

## 실행

빌드·설치·서버가 필요 없다. `index.html`을 브라우저에서 직접 열면 된다(`file://` 포함).
**외부 요청 0건** — 이미지·웹폰트·오디오 파일·CDN·SDK를 쓰지 않고 CSS 도형과 인라인 SVG, Web Audio 합성만 사용한다.

```
games/game-04/
├── index.html   구조 · 결과 모달 · live region
├── style.css    산장/선반 장식 · 5×4 그리드 · 반응형 · 감소된 모션 · forced-colors
└── script.js    재료 20종 SVG 원본 · seed 보드 생성 · 점수/타이머 · 상태머신 · 입력 통합
```

## 규칙

| 항목 | 값 |
|---|---|
| 보드 | 5열 × 4행 = 20칸 (목표 정확히 5칸) |
| 오답 재료 | 5~8종, 종당 최대 4칸 — 5칸인 재료는 목표뿐 |
| 제한 시간 | 30초 (첫 유효 입력부터, 별도 시작 버튼 없음) |
| 정답 | `100 × 콤보` — 콤보 `1.00 → 1.25 → 1.50 → 1.75 → 2.00`(상한) |
| 오답 | 시간 −2초 · 점수 −50(하한 0) · 콤보 1.00 초기화 · 칸은 남고 450ms X 표식 |
| 승리 | 5개 수집 → `floor(남은 초) × 10` 시간 보너스 1회 가산 |
| 패배 | 5개 미만인 채 남은 시간 0 |
| 경합 | 마지막 정답과 만료가 겹치면 `finishOnce`가 먼저 확정된 쪽만 기록 |

목표와 **같은 실루엣 계열**(예: 배↔가지, 양파↔마늘, 토마토↔사과)은 같은 라운드에 오답으로 등장하지 않는다.
정오답은 색상만이 아니라 아이콘·한국어 이름·✓/✕ 표식·문구로 함께 전달한다.

## 입력

| 입력 | 동작 |
|---|---|
| 포인터 / 터치 | 칸 탭 (드래그 불필요, `touch-action: manipulation`) |
| 방향키 | 5×4 좌표 이동, 경계에서 래핑 없이 같은 행/열 유지 |
| Enter / Space | 선택 |
| R | 결과 화면에서 다시 찾기 |
| M | 음소거 토글 (`localStorage` 저장, 실패해도 정상 동작) |

포인터·터치·키보드는 모두 같은 `selectCell(id)` 경로를 쓴다.
수집 완료 칸은 `disabled`가 아니라 `aria-disabled="true"`라 키보드 좌표 이동에서 건너뛰지 않는다.

## URL 파라미터

- `?seed=<정수>` — 동일 보드 재현. 지정 시 재시작해도 같은 보드가 나온다(QA 전용, 미지정 시 매 판 새 보드).
- `?test=1` — 규칙 순수 함수 자기 테스트(60개 seed 보드 불변식, 콤보·감점·보너스, `finishOnce`)를 실행하고 좌하단 패널과 콘솔에 결과를 출력한다.

## 접근성

`aria-label="N행 M열, 재료명"`, 진행 상황 `aria-live="polite"`(매초 타이머는 읽지 않고 10초·5초만 알림),
`:focus-visible` 3px 윤곽선, 최소 44px 타깃, `prefers-reduced-motion`·`prefers-contrast`·`forced-colors` 대체 스타일.
AudioContext는 실제 사용자 입력 이후에만 생성한다.
